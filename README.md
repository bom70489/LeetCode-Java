# LeetCode Java Solutions

A collection of Java practice solutions organized by problem topic.

## Project Structure

- `arrays/` — array and sequence problems
- `dynamic-programming/` — dynamic programming problems
- `strings/` — string processing problems
- `README.md` — repository overview and run instructions

## Run a Solution

Compile from the repository root and set the classpath to the solution's folder. For example:

```bash
javac arrays/Search.java
java -cp arrays Search
``

Use the matching folder and class name for each solution.
